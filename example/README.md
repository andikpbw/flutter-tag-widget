# tag_widget_example

Interactive example app demonstrating the features of `tag_widget`:
- Interactive `TagInputWidget` with delimiter splitting, backspace deletion, and live autocomplete suggestions.
- Custom tag silhouettes (`pill`, `rounded`, `square`, `priceTag`, `ticket`, `ribbon`) and 6 theme presets (`modern`, `glass`, `neon`, `gradient`, `outlined`, `soft`).
- Multi-select and single-select `TagGroupWidget` with `"All"` chip and collapsible `+N more` overflow expansion.
- Weighted interactive `TagCloudWidget` with palette and heat-gradient modes.
- `TagFormField` validation.

> Supported by [Humanize AI](https://humanize.id)
