## 1.0.0

* Initial stable release of `tag_widget`.
* Added `TagWidget` supporting labels, subtitles, leading avatars/icons, count badges, selection states, delete actions, tooltips, and custom shapes (`pill`, `rounded`, `square`, `priceTag`, `ticket`, `ribbon`).
* Added 6 modern theme presets in `TagStyle`: `modern`, `glass`, `neon`, `gradient`, `outlined`, and `soft`.
* Added `TagInputWidget` with multi-delimiter tag creation, multi-tag clipboard paste splitting, backspace-to-delete navigation, duplicate rejection feedback, prefix formatting (`#`, `@`), and live autocomplete suggestions.
* Added `TagGroupWidget` supporting single-choice and multi-choice filtering, optional `"All"` toggle chip, horizontal scroll and wrap layouts, and collapsible `+N more` overflow expansion.
* Added `TagCloudWidget` for weighted topic visualization with dynamic scaling and heat-gradient or palette coloring.
* Added `TagController` for programmatic tag CRUD, selection management, filtering, and sorting.
* Added `TagFormField` for full Flutter `Form` validation integration.
* Added animated SVG UI previews in `doc/` and `README.md`.
